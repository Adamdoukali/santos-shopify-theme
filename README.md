# Santos Haute Couture — Official Shopify Theme

Official bespoke theme for the Santos Haute Couture store (`https://a9xpr3-x0.myshopify.com`).

## Architecture & Features
- **Online Store 2.0 Compliant**
- **Sections**:
  - Hero Video with auto-looping teaser
  - Les Collections Category Grid (Manteaux, Ensembles, Robes, Jeans)
  - Manteaux d'Exception & Ensembles Couture Signature Sections
  - Exclusive Selection 4-Column Grid
  - La Maison Santos Atelier Craftsmanship Showcase
  - Reassurance Trust Bar
- **Templates**:
  - `collection.liquid`: Centered 4-card compact boutique line, instant client-side category filtering (`MANTEAUX`, `ENSEMBLES`, `ROBES`, `JEANS`, `TOPS`), sorting dropdown, and automated image fallbacks
  - `product.liquid`: Haute couture product page with gallery switcher, variant options, and AJAX cart integration
- **Assets**:
  - Modern typography (FT Kunst Grotesk, PP Neue Montreal, ABC Arizona)
  - Web-optimized H.264 video assets
  - High-resolution editorial photography
- **Engine**:
  - `santos-theme.js` with Shopify AJAX cart, instant search suggest, and drawer controls
